# 11vatedTech Design Director / Frontend Fidelity

11vatedTech interfaces must not look like generic AI dashboards.

This skill owns frontend design execution and rendered visual QA. Pair with `11vt-creative-production` when work requires full creative direction, assets, motion language, 3D/rendering, audiovisual polish, or project visual canon.

## Non-negotiables

- Working is not finished.
- Styled is not designed.
- High resolution is not high fidelity.
- Effects are not art direction.
- Source code is not visual evidence.

Do not rely on dark backgrounds, neon gradients, glass cards, glowing borders, particles, blur blobs, rounded-card grids, or icon circles unless product concept justifies them.

## Phase 1 — Understand

Identify:

- product identity
- audience
- emotional objective
- content hierarchy
- usage context
- platform
- technical constraints
- visual canon or missing canon
- states that must be designed, not left as defaults

## Phase 2 — Art direction

Define coherent visual concept from product meaning:

- color roles and contrast language
- typography personality, scale, tracking, leading
- spatial rhythm and composition
- material, texture, lighting, and depth
- shape, icon, illustration, and asset language
- responsive recomposition rules
- motion/interaction tone

Do not merely produce a palette.

## Phase 3 — Composition

Establish:

- eye path and focal hierarchy
- foreground/middle/background relationship
- grid and intentional exceptions
- component language
- interaction model
- accessibility constraints
- loading/empty/error/success states

## Phase 4 — Implementation

Implement production-quality UI with semantic structure, accessible controls, real states, keyboard/focus behavior, responsive layouts, reduced-motion support, and no dead interactions presented as final.

## Phase 5 — Visual QA

Inspect running product when possible:

- browser snapshot/screenshot
- desktop/tablet/mobile viewports
- interaction states and transitions
- console/network/server errors
- accessibility tree
- important CSS values/selector inspection
- obvious performance/layout overflow issues

## Phase 6 — Critique and improve

Critique like senior creative director. First acceptable pass is not enough for high-fidelity work.

If result is weak, escalate beyond padding/colors/shadows:

component styling → layout → composition → visual grammar → art direction → asset strategy → interaction model.

Use `references/visual-qa-checklist.md` before claiming UI work visually inspected.
