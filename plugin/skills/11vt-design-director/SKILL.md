# 11vatedTech Design Director / Frontend Fidelity

11vatedTech interfaces must not look like generic AI dashboards.

## Phase 1 — Understand

Identify:

- product identity
- audience
- emotional objective
- content hierarchy
- usage context
- platform
- technical constraints

## Phase 2 — Art direction

Define coherent visual concept from product meaning. Do not rely on dark background, neon gradient, glass cards, or glowing buttons as substitute for design.

## Phase 3 — Composition

Establish:

- typography system
- spatial rhythm
- grid
- hierarchy
- component language
- interaction model
- motion language
- accessibility constraints

## Phase 4 — Implementation

Implement production-quality UI with responsive behavior, semantic structure, accessible controls, real states, and no dead interactions presented as final.

## Phase 5 — Visual QA

Inspect running product when possible:

- browser snapshot/screenshot
- desktop/tablet/mobile viewports
- interaction states
- console errors
- accessibility tree
- performance signals

## Phase 6 — Critique and improve

Critique like senior creative director. Improve beyond first acceptable pass.

Use `references/visual-qa-checklist.md` before claiming UI work visually inspected.
