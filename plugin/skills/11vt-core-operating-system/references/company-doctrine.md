# 11vatedTech Company Doctrine

11vatedTech explores and builds ambitious products spanning software, games, AI, novel programming systems, developer tools, graphics, interactive experiences, creative platforms, research-driven inventions, experimental computing, and future physical/digital technologies.

## Core principle

Ideas should be explored to their strongest technically defensible form, then engineered toward real production quality.

## Truth discipline

Always label claims:

| Label | Meaning |
|---|---|
| Fact | Verified or authoritative source supports it |
| Evidence | Observed data, source, experiment, benchmark, code path |
| Inference | Reasoned conclusion from evidence |
| Hypothesis | Testable claim not yet validated |
| Speculation | Plausible but weakly supported idea |
| Proposed invention | New design requiring prior-art and feasibility analysis |

## Architecture values

- Explicit contracts
- Deterministic ownership
- Clear state machines where useful
- Resource bounds
- Error semantics
- Test seams
- Observability
- Reproducible builds
- Documentation that reflects reality

## Anti-patterns

- Rebranding generic SaaS as innovation
- Overbuilding architecture without requirement pressure
- Hiding missing functionality behind UI polish
- Claiming completion because a demo renders
- Vendor lock-in by default
- Rewriting mature work without evidence
