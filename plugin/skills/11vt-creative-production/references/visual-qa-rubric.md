# Visual QA Rubric

Score 0–4. Any 0 in identity, hierarchy, accessibility, or rendered evidence blocks production-ready visual claim.

| Dimension | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| Identity | generic/no thesis | borrowed trend | some subject cues | distinct grammar | unmistakable product world |
| Concept | absent | slogan only | partial metaphor | coherent | memorable and extensible |
| Composition | accidental | clutter/empty | serviceable | directed eye path | cinematic/editorial control |
| Hierarchy | unclear | competing elements | readable | strong | effortless |
| Typography | default | inconsistent | competent | expressive | type is artwork |
| Material/lighting | fake | decorative effects | coherent locally | coherent system | physically/emotionally convincing |
| Assets | placeholders | reused decoration | adequate | meaningful | production-defining |
| Motion | absent/jarring | decorative | useful feedback | choreographed | signature temporal language |
| Interaction feel | dead | inconsistent | usable | responsive | delightful, legible, tactile |
| Responsive design | broken | cramped | adapted | intentionally recomposed | excellent across devices |
| Accessibility | blocked | weak labels/contrast | acceptable | strong | inclusive without fidelity loss |
| Performance | unstable | visibly heavy | acceptable | smooth | profiled/optimized |
| Originality | AI default | trend clone | modest | fresh | could define product category |
| Rendered evidence | none | source-only | one viewport | multi-viewport + state | evidence-led iteration |

## Critic questions

- Where does eye go first? Is that intentional?
- Does screenshot explain product identity without chat context?
- Is interface mostly rounded rectangles with effects?
- Do assets carry meaning or hide lack of design?
- Would removing glow/gradient reveal weak structure?
- Are empty/loading/error/win/loss states designed?
- Does motion communicate state, hierarchy, space, or emotion?
- Does mobile feel designed or collapsed?
- What should be removed, not polished?
- What requires escalation beyond styling tweaks?

## Finding format

Severity: Critical/High/Medium/Low
Evidence: viewport/screenshot/selector/state/file
Issue: concrete visual failure
Impact: why it lowers product quality or usability
Fix: conceptual or implementation path
Validation: how to prove correction
