# 11vatedTech Project Bootstrap

Transform a repository into an intelligently governed 11vatedTech product repository without overwriting existing work.

## Modes

- Brand-new project: create stack-neutral skeleton and manifest.
- Existing project: perform repository archaeology first.
- Mature project: preserve architecture and docs; add only missing operational index/canon.
- Research/invention repo: emphasize research artifacts, evidence, feasibility, experiments.
- Game repo: add asset/runtime/frame/performance canon when applicable.
- AI/ML repo: add model manifest/evaluation and reproducible environment notes when applicable.
- Web/app repo: add run/verify/visual QA canon when applicable.
- Native C++ repo: identify intended Windows/toolchain path before installing anything.

## Archaeology before writes

For existing repos reconstruct product purpose, architecture, modules/packages, build/runtime/test paths, docs, generated/vendor/assets policy, CI, configuration, and Git state.

## Artifacts

Create only missing applicable files: `11vt.project.yaml`, concise `CLAUDE.md`, `CURRENT_STATE.md`, relevant docs, project `.claude/skills/project-*`, and local verification scripts.

## Guardrails

Never overwrite existing CLAUDE.md/docs/settings without reading and merging. Manifest is operational index, not full docs. Canon records current reality, not aspirations.
