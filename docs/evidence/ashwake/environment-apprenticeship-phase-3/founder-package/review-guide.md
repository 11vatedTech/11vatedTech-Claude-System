## Suggested review sequence

1. Read each `concept-sentence.md`.
2. Watch each walkthrough video twice — once with sound off, once playing that option's audio prototypes.
3. View grayscale folders; answer whether SAFE vs HOSTILE remains readable without color.
4. Open `state-identification-form.md` and answer per option.
5. Skim material contact sheets; judge material differentiation under neutral/grazing/production light.
6. Answer the 14 questions below.

## The 14 review questions

1. Which world makes you most curious to explore?
2. Which feels most original?
3. Which feels most like a real place rather than a test level?
4. Which relic interaction is easiest to understand?
5. Which SAFE state is clearest?
6. Which HOSTILE state is clearest?
7. Which restoration event feels most meaningful?
8. Which world has the strongest emotional identity?
9. Which looks closest to professional game quality?
10. Which feels like it could become a larger universe?
11. Which one would you personally want to keep playing?
12. What looks primitive in each?
13. What confuses you in each?
14. What would you combine, if anything?

- Performance numbers come from editor-mode proxies, not packaged builds.
