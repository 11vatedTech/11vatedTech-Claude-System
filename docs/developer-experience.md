# Developer Experience

Founder-facing workflows are intentionally small:

- `11vt-status` — reconstruct current project state.
- `11vt-project-bootstrap` — create/repair project canon and manifest.
- `11vt-product-lifecycle` — govern substantial work from discover to canonize.
- `11vt-testing-verification` / `project-verify` — prove work with evidence.
- `11vt-independent-reviewer` — read-only critique for high-value changes.
- `11vt-release-engineering` / `project-release` — release gate.

Avoid dozens of narrow commands. Add more only after real product calibration proves need.
