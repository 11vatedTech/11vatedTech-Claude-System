# Product Maturity Model

- CONCEPT: research and product definition.
- FOUNDATION: architecture and essential infrastructure exist.
- FUNCTIONAL: primary workflows execute.
- INTEGRATED: major systems operate together.
- HARDENED: failure handling, security, performance, UX, reliability addressed.
- RELEASE CANDIDATE: release gates satisfied except final approval.
- RELEASED: versioned distributable product exists and release evidence is recorded.

Do not call FUNCTIONAL software production-ready. Do not call a visual mockup finished frontend. Do not call one successful run validation.
