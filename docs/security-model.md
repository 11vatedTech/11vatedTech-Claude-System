# 11vatedTech Claude System Security Model

## Assets

- Claude settings and credentials
- 11vatedTech skills/plugin source
- project source repositories
- secret files and environment variables
- 9Router key/provider routes

## Controls

- no secrets in skills or docs
- source ledger pins external skill provenance
- deterministic hooks block obvious destructive/secret operations
- plugin remains local/internal unless explicitly published
- update procedure requires review before adoption
