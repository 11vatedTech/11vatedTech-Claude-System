# 11vatedTech Product / Repository Boundary

The Foundry is company capability infrastructure, not the product portfolio. Independently sellable, deployable, maintainable, or licensable products normally own separate Git repositories. Product repositories and workspace containers are never staged into the Foundry. Pumkit is an external PRODUCT_REPOSITORY reviewed read-only by Wave A. GrowthOS is an external PRODUCT_REPOSITORY classified as PRODUCT_REPOSITORY with a recovered baseline extracted into the Foundry as bounded evidence only; the canonical GrowthOS source remains its own independent repository outside the Foundry.
