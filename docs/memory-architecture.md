# 11vatedTech Memory Architecture

## Layers

### Durable company principles

Global memory/reference. Examples:

- development philosophy
- quality bar
- research standards
- dependency philosophy
- architectural preferences
- completion language

### Project canon

Repository-local. Examples:

- architecture
- terminology
- invariants
- build/run/test commands
- design system
- decisions/ADRs
- validation procedures
- release process

### Session/transient state

Conversation-local unless needed for immediate continuation. Examples:

- currently failing test
- temporary experiment
- active branch
- intermediate debugging findings

## Memory write rules

1. Verify durable lesson.
2. Decide global vs project-specific.
3. Update appropriate reference or memory file.
4. Link related memories.
5. Keep index compact.
6. Do not store secrets.
7. Do not duplicate repo facts already in code/docs/git history.
